# Inventory Gate, Review Gate, and Prompt Import

Blind generation duplicates against stale decks; unreviewed bad **Cards** become permanent **Legacy Backlog**; parked **Lotes** get forgotten. The pipeline is **Inventory Gate** (fresh **Deck Export** ≤ 7 days) → generate/validate → **Review Gate** (Bruno edits) → **Prompt Import** at a studyable size (shrink the **Lote** when New is high). No best-effort inventing, no auto-import, no stockpile-for-later.
