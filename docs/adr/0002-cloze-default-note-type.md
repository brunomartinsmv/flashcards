# Cloze as the default note type

New **Lotes** must train retrieval toward **Fluency**, and automation needs one import shape across languages. All new **Cards** use Anki **Cloze** with a single `{{c1::Target}}`; **Support** (L1 or in-context) lives in Extra/notes. Basic/`_____` remains legacy only and is not the template for generation.
