# Process Skill plus Language Profiles

Bruno needs the same weekly pipeline for every language, but Spanish (weaker, chunk-heavy, more L1 Support) and English (~7/10, word-in-context, In-context Support) diverge in content rules. We keep one **Process Skill** for shared pipeline/policy and short **Language Profiles** for per-language overlays, instead of cloning full skills or packing everything into one monolithic file.
