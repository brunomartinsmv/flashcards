# Scripts da coleção CPA

Execute `python3 flashcards/cpa/apostila/scripts/gerar_colecao.py` e `python3 flashcards/cpa/apostila/scripts/validar_colecao.py` na raiz. Ambos precisam da extração privada `flashcards/cpa/fontes/apostila_cpa.txt`. Consulte o [guia da coleção](../README.md) e o [guia das fontes](../../fontes/README.md). Scripts sob Apache 2.0.
