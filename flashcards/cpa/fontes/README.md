# Referências CPA

`plano_estudos.json` descreve o plano de estudos; `proveniencia.json` identifica os arquivos locais e a edição. O PDF e `apostila_cpa.txt` são fontes privadas, ignoradas pelo Git. Para gerar a extração local, use `pdftotext -layout livros/Apostila_CPA.pdf flashcards/cpa/fontes/apostila_cpa.txt`. O gerador e o validador da apostila precisam dessa extração; ela não é necessária para importar os cartões já distribuídos.
