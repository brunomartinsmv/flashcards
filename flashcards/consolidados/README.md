# Consolidados de idiomas

Os lotes originais continuam nas pastas `flashcards/spanish/` e
`flashcards/english/`. Estes arquivos reunem os lotes atuais para consulta ou
importação, sem substituir as fontes.

| Arquivo | Conteúdo | Organização |
| --- | --- | --- |
| `espanhol/espanhol_cloze.tsv` | Cloze de reconhecimento dos lotes de 24/07, 16/08 e 17/08 | Tags de tema na coluna `Tags` |
| `espanhol/espanhol_producao.tsv` | Variante Basic de produção de 24/07 | Mantida separada do twin Cloze |
| `espanhol/espanhol_basic.tsv` | Lotes Basic de maio e junho | Tag de origem por lote; duas frentes repetidas foram consolidadas em uma |
| `ingles/ingles_cloze.tsv` | Lote Cloze de inglês de 17/08 | Tags de tema na coluna `Tags` |

Os temas dos lotes Cloze podem ser filtrados pelas tags no Anki. Os lotes
Basic antigos não tinham tags temáticas; por isso, o consolidado mantém a
origem de cada cartão sem atribuir temas por inferência. Todos os arquivos
usam tabulação, apesar de alguns lotes originais não terem cabeçalho de
importação.
