# Gerador de frases

`frases.json` contém 450 intenções alinhadas em português, italiano, espanhol e inglês. Execute `python3 scripts/frases/gerar_frases.py` na raiz para gerar os CSVs em `flashcards/<idioma>/`. O manifesto registra contagens e a comparação local de frentes. Relatórios de importação ficam locais e são ignorados pelo Git.
